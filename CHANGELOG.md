# Changelog

Notable changes to this project are recorded here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

The guide's build package uses `0.0.0` as a development placeholder.
The implementation packages remain unreleased on crates.io, npm and opam.

## [Unreleased]

### Added

- A shared guide to the component model and automatic bug finding, including
  scheduling, service integration, observability, invariants and projections.
- Tested examples in Rust, OCaml and TypeScript, including a generated test
  that finds, shrinks and reproduces a payment bug, with language switching
  and implementation sources pinned as submodules.
- A guide site builder, navigation checks and a GitHub Pages deployment workflow.
